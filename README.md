# Vedaselvam Kausshik Revanth - Flight Log SPA

This is a simple single-page flight log application using:

- Python Flask
- SQLite database
- HTML, CSS, JavaScript

## Features

- Login page with username and password
- View all flight logs
- Create flight logs
- Update flight logs
- Delete flight logs
- Search by flightID
- Create user
- Delete user

## Default Login

```txt
Username: admin
Password: admin123
```

## How to Run

### 1. Install Python

Make sure Python is installed.

Check:

```bash
python --version
```

### 2. Install Flask

Inside this project folder, run:

```bash
pip install flask
```

### 3. Run the app

```bash
python app.py
```

### 4. Open in browser

Go to:

```txt
http://127.0.0.1:5000
```
