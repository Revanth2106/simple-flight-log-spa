# Vedaselvam Kausshik Revanth - Flight Log SPA

This is a simple single-page flight log application using:

- Python Flask
- SQLite database
- HTML, CSS, JavaScript

## Features

- Login page with username and password
- View all flight logs
- Create flight logs
- Update flight logs
- Delete flight logs
- Search by flightID
- Create user
- Delete user

## Default Login

```txt
Username: admin
Password: admin123
```

## How to Run

1. Download the ZIP from GitHub

2. Extract the ZIP

3. Open the extracted folder:
simple-flight-log-spa-main

(Note: GitHub automatically adds "-main" to the folder name)

4. Open terminal inside this folder

5. Run:
python app.py

6. Open browser:
http://127.0.0.1:5000
